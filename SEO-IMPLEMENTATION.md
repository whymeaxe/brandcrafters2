# Embassy of Education — SEO implementation

This build adds technical and on-page SEO for the Embassy of Education website while preserving the existing premium design.

## Included

- Unique page titles and meta descriptions for the main routes.
- Canonical URLs pointing to `https://embassyofeducation.co.in`.
- Open Graph and Twitter metadata.
- `robots.txt` and XML sitemap covering the main routes and destination pages.
- LocalBusiness structured data for Embassy of Education, including the verified Vadodara office details supplied in the project brief.
- AboutPage / Person structured data for founder Avdhesh Brahmbhatt.
- Destination-specific metadata.
- Local search wording such as "visa agency in Vadodara" and relevant visa-service terms used naturally rather than keyword stuffing.
- Image alt text for the new founder and gallery assets.

## Before launch

1. Configure the production domain `embassyofeducation.co.in` on the hosting platform if it is not already connected.
2. Verify the domain in Google Search Console.
3. Submit `https://embassyofeducation.co.in/sitemap.xml` in Search Console.
4. Claim and fully complete the official Google Business Profile for the Vadodara office.
5. Validate the LocalBusiness structured data with Google's Rich Results Test and inspect the live pages in Search Console.
6. Publish useful, original visa guides over time. Strong rankings for competitive terms such as "best visa agency" depend on content quality, local prominence, links, reputation and user signals; no code change can guarantee a #1 position.
